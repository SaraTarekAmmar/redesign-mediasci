
## Additional authenticated routes

The global `/issues` route rendered a 15-row issues table with issue keys such as DBP-1 through RERP-15, summaries, types, statuses, priorities, assignees, due dates, search, filters, and a Create Issue action. The project route `/projects/1` rendered the Digital Banking Platform overview with project metadata, health, completion, schedule and budget cards, issue status breakdown, team members, sprints, and links to Edit Project, Issues, Board, Backlog, Roadmap, and Reports. This confirms the seeded project-specific data and navigation are available in the standalone frontend.
